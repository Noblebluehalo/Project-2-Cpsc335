## Project Overview

This project implements two algorithms in C++:

1. **Algorithm 1 – Minimum Turns for Knights to Capture**  
   Uses **Breadth-First Search (BFS)** over joint knight positions to find the minimum number of *turns* (rounds) for one knight to capture the other on an infinite chessboard.

2. **Algorithm 2 – String Run Encoding**  
   A simple **run-length encoding** algorithm that compresses consecutive duplicate characters (e.g., `ddd` → `3d`).
